# Security Policy

## Reporting a Vulnerability

The maintainers take security very seriously.  If you discover a
vulnerability, please **do not open a public GitHub issue** until we
have had a chance to assess and address it.  Instead, use one of the
following private disclosure channels:

* **Email:** Send a report to `security@unixerius.dev` (replace with your own
  address).  Include a detailed description of the issue, steps to
  reproduce it, and any suggested fixes.
* **Security advisories:** You may also use the GitHub
  [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/collaborating-on-security-advisories/about-private-vulnerability-reporting)
  feature to notify the maintainers.  This creates a private thread
  that is not visible to the public.

We aim to acknowledge all reports within a few business days and will
work with you to coordinate a fix and disclosure timeline.  Please
avoid disclosing details of any vulnerabilities publicly until we
publish a patch and an advisory.
